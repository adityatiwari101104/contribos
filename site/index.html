Why

        

          
AI made pull requests cheap. Maintainers wrote rules.

          
Agents can open a PR in minutes, so projects now spell out what they accept: disclose AI use, no unattended agents, claim the issue first, tests and changelog entries. The rules are spread across files nobody reads at the right moment. ContribOS reads them for you.

For coding agents

        

          
Give your agent the rules before it writes code.

        

      

      

        

          
ContribOS runs as an MCP server, so Claude Code, Cursor, Codex and other agents can call policy, brief, setup, check, review, claim, find and tone directly.

          
agent-rules writes a local skill for your agent with the repo's rules, plus hooks that stop it opening PRs or posting comments on its own. Nothing is committed to the repo.

          
Listed on the official MCP Registry and in awesome-mcp-servers.

        

        

          # add the MCP server to Claude Code
          claude mcp add contribos -- python -m contribos mcp
           
          # or teach an agent this repo's rules
          contribos agent-rules . --ai "Claude Code"
        

      

    

  


  

    

      

        
FAQ

        
Questions, answered.

      

      

        

          Does ContribOS open pull requests or post comments for me?
          
No. It never opens PRs, posts comments or claims issues. It reads and points; you decide and act. The hooks that agent-rules writes exist to stop an agent doing those things on its own.

        

        

          Where do the rules come from?
          
From the repo itself: contributing guides, PR and issue templates, AI policy files, docs pages and recent git history. Each finding quotes its file and line, so you can check it in one click.

        

        

          Does it send my code anywhere?
          
ContribOS has no server of its own. It clones public repos from GitHub and caches them on your machine, and some commands read issue data from the GitHub API. Your own code stays local.

        

        

          What if a repo has no written AI policy?
          
It says so instead of guessing, as with Flask in the demo above, and suggests disclosing AI use anyway as a courtesy.

        

        

          How accurate is it?
          
It reads rules with text patterns, not a language model, so unusual wording can slip past it. That is why every rule links to its source. In our 11-repo check, version 0.2.3 gets 10 right; uv's org-wide policy, which lives in a separate repo, is still open as issue #10.

        

        

          Can I contribute?
          
Yes. Hacktoberfest issues are open, and outside contributors have already had PRs merged. See open issues ›
