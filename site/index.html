FAQ

        
Questions, answered.

      

      

        

          Does it open pull requests or post comments for me?
          
No. It never opens PRs, posts comments or claims issues. It reads and points; you decide and act. The hooks that agent-rules writes exist to stop an agent doing those things on its own.

        

        

          Does it send my code anywhere?
          
ContribOS has no server of its own. It clones public repos from GitHub and caches them on your machine, and some commands read issue data from the GitHub API. Your own code stays local.

        

        

          How accurate is it?
          
It reads rules with text patterns, so unusual wording can slip past it. That is why every rule links to its source. In our 11-repo check, version 0.2.3 gets 10 right; uv's org-wide policy, which lives in a separate repo, is still open as issue #10.
